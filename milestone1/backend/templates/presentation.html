The Challenge & The Solution

Core Concept

The Recruiting Bottleneck

Modern HR departments struggle to sift through hundreds of applications per vacancy, leading to lost time and missed top talent.

  • Manual Screening Overhead: Average resume review takes 23 seconds, prone to fatigue and subjective bias.
  • Inconsistent Document Formats: Parsing resumes in different formats (PDFs, DOCX files) fails or skips details.
  • Opaque Skills Alignment: Identifying who has the exact skill set requirements vs. filler buzzwords is difficult.

TalentSphere Elevate Approach

We built a multi-stage intelligent system that automates CV parsing, scoring, and candidate prioritizing within a unified recruiter dashboard.

  • Ingestion Engine: Automatically extracts text from PDF and Word resumes.
  • spaCy NLP Entity Extractor: Extracts email, phone, candidate names, and filters core technical competencies.
  • ATS scoring & ranking: Normalizes candidate features against job descriptions instantly.

ATS Skills Match & Gap Analysis

candidate/skill_matching.py

Fit Scoring Logic

The system calculates skills overlap against job requirements, highlighting matching strengths and missing keywords for gap correction.

def calculate_skill_match(candidate_skills, required_skills):
    candidate_set = {s.lower() for s in candidate_skills}
    required_set = {s.lower() for s in required_skills}
    
    matched = candidate_set.intersection(required_set)
    missing = required_set.difference(candidate_set)
    
    score = 0
    if required_set:
        score = round((len(matched) / len(required_set)) * 100)
        
    return {
        "score": score,
        "matched_skills": list(matched),
        "missing_skills": list(missing),
    }

Recruiter Prioritization

recruiter/ranking.py

Priority Scoring & Normalization

To rank applicants objectively, recruiter tools compute an aggregated priority ranking. It incorporates skills overlap and candidate experience matching coefficients.

  • Normalization: Converts strings (e.g. "3+ Years", "2 years") into floating-point numbers.
  • Weighting: Blends Skills Fit Index (70% weight) with Experience Match Score (30% weight).
  • Sorting: Ranks applications dynamically, allowing recruiters to focus on premium qualified candidates.

class CandidateProfile(models.Model):

Future Roadmap & Next Steps

Generative AI & Semantic Architecture

Milestone 2 focuses on upgrading the baseline matching algorithm from rule-based filters to context-aware generative processing.

  • Gemini API JSON Extraction: Integrates LLMs to extract clean, structured profile details directly from freeform resumes.
  • OCR Scanning Ingestion: Adds Tesseract / PDFplumber rasterized image processing to capture scanned text.
  • Semantic Skills Embeddings: Calculates similarity scores using Vector Embeddings (e.g. matching "Frontend" with "React.js" semantically).
1. Generative AI JSON Schema Ingestion

Using Gemini structured outputs to parse complex sections (Work Experience dates, GPA, University names) with zero rules configuration.

2. Deep Experience Timeline Modeling

Structuring candidate work history timelines (Job title -> Company -> Years) into chronological charts for recruiters.

3. Sentence Embeddings Matcher

Bridges the terminology gap by understanding that a candidate with "Deep Learning" is highly relevant to a "Machine Learning" requirement.
